The 2026 Crisis

Why South Texas Reached the Brink

Across 25 years and five consecutive State Water Plans, Texas planners never projected a municipal water shortage in the 2020s. Here is why the crisis happened.

7.7% Reservoir Capacity

In mid-April 2026, Lake Corpus Christi and Choke Canyon plummeted to 7.7%, breaching the 75,000 acre-foot safe-yield reserve where intake pumps cavitate and gravity flow fails.

The 2015 State Model Freeze

Official Texas Water Availability Models (WAM) were granted a budget variance freezing hydrology at 2015. State tools were legally and technically blind to the recent decade-long mega-drought.

The $50k Industry Barrier

Rural Water Control Districts (WCIDs) facing emergency drought can't wait 6 months and pay $50,000 for consulting models, while un-audited Excel sheets invite catastrophic formula errors.

Core Capabilities

Engineered for Transparent Decision-Making

A deterministic screening engine paired with explainable machine learning and cryptographic audit trails.

Deterministic Scenario Engine

Resamples synchronized multi-station historical windows (NOAA GHCN-Daily 1991–2025). Zero synthetic rain; zero fabricated days. Scales precipitation while strictly maintaining spatial concurrence.

Unsupervised K-Means AI

Maps 300 candidate droughts into an 8-dimensional hydrologic feature space (deficit, duration, concurrence, summer timing, dry-spell runs). Clusters candidates into 6 non-redundant archetypes.

Mass-Conserving Simulation

Simulates multi-reservoir storage drawdowns, evaporation, and municipal intake cavitation with strict physical mass conservation (numerical error |Error| < 10⁻⁶ Ac-Ft).

Demand Equity Modeling

Test policy interventions: evaluate the controversial Drought Surcharge Exemption Fee (DSEF) vs. mandatory industrial curtailment vs. residential Stage 3 restrictions.

Crop & Wildfire Interoperability

Computes daily crop evapotranspiration (ETc = ETo × Kc) across South Texas cash crops (cotton, sorghum, corn) and tracks deep soil moisture via Keetch-Byram Drought Index (KBDI).

Cryptographic Audit Trail

Every edit, multiplier, and conflict disposition invalidates previous approvals and compiles into a verifiable .zip bundle with SHA-256 manifests and publication-ready PDF briefs.

Engineering Documentation

Technical Specifications & Architecture

Transparent equations, data pipelines, and scientific boundary definitions for hydrologists and technical judges.

1. End-to-End Data Pipeline Architecture

BASIN operates as a strictly bounded L0/L1 screening pipeline that bridges observational meteorology and formal hydrologic reservoir yield modeling:

[NOAA GHCN-Daily Snapshot 1991–2025] ──► [Synchronized Window Resampling (PCG64)] │ ▼ [8D Feature Vectorization] ──────────────► [Local K-Means Clustering (k=6)] │ ▼ [Shortlist Exemplar Selection] ──────────► [Mass-Conserving Storage Simulation] │ ▼ [Cryptographic Replay Verifier] ─────────► [PDF Executive Brief & Verified ZIP]

2. Mathematical Formulation: 8D Hydrologic Clustering

Rather than cherry-picking arbitrary worst cases, candidate drought windows are projected into an 8-dimensional normalized hydrologic feature space \(\mathbf{x}_i \in \mathbb{R}^8\) before unsupervised grouping:

x_i = [ Deficit / E[Rain], Duration / 365, Concurrence, SummerFraction, MaxDrySpell / 365, PeakSeasonRatio, StationSkew, VolumetricSeverity ]

A deterministic K-Means model partitions the 300 candidates into \(k=6\) archetypes (e.g., acute summer flash drought, chronic multi-year drying, localized sub-basin drop). The cluster exemplar nearest each centroid \(\mu_k\) is selected for the shortlist.

3. Mass-Conserving Reservoir Balance Equation

Storage drawdown simulations strictly enforce discrete daily mass conservation across the multi-reservoir network:

S_{t} = S_{t-1} + I_t(R_t) - E_t(S_{t-1}) - D_t(\text{policy}) - \text{Spill}_t

Where \(S_t\) is storage volume, \(I_t\) is inflow driven by stressed rainfall \(R_t\), \(E_t\) is net lake-surface evaporation, and \(D_t\) is sector-curtailed municipal/industrial demand. Simulations enforce: \(\sum |\text{Error}| < 10^{-6}\) acre-feet.

4. Dual AI Subsystem & Zero-Hallucination Assistant

BASIN decouples conversational natural language processing from hydrologic calculation:

  • The Core Statistical AI: Unsupervised Scikit-Learn K-Means grouping over the 8D feature space.
  • The Interface Assistant: An embedded, SHA-256 pinned local model (Qwen-2.5-3B-Instruct GGUF) running on CPU with AVX2 acceleration via llama-cpp-python.
  • Deterministic Tool Binding: The language model never computes numbers. It maps user queries into 13 registered Python calculation tools (e.g., explain_ranking, check_concurrence, run_sensitivity) with strict parameter validation.

5. Texas Engineering Practice Act (§ 1001) Compliance

Under Texas law, un-licensed software cannot issue binding water plan adequacy certifications. BASIN is engineered around strict scientific contracts:

Contract Status: Output contains NO statutory "safe/unsafe" verdict fields. Output Class: Agile L0/L1 Screening Workbench for licensed P.E. review.

All reports explicitly document input assumptions, airport station proxy boundaries, and reserve limits, serving as an auditable technical handoff directly ingestible into Texas WAM Run 3 and USACE HEC-ResSim.
