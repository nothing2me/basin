# OPTIONAL native runtime for the embedded Qwen assistant. BASIN's core never needs it.
#
# Supported target: Windows x64, CPython 3.12, inside the BASIN .venv, AFTER
# requirements.txt is installed. Install it with the checked helper rather than pip
# directly, so the platform, venv and import checks run:
#
#     .venv\Scripts\python.exe scripts\install_native_runtime.py            (install)
#     .venv\Scripts\python.exe scripts\install_native_runtime.py --repair   (reinstall)
#     .venv\Scripts\python.exe scripts\install_native_runtime.py --check    (report only)
#
# Source: the upstream-documented CPU wheel index (llama-cpp-python README, "Pre-built
# Wheel"), which links to the GitHub release asset
#   https://github.com/abetlen/llama-cpp-python/releases/download/v0.3.35/llama_cpp_python-0.3.35-py3-none-win_amd64.whl
# uploaded by github-actions[bot] on 2026-08-17 (7,086,788 bytes). PyPI carries only the
# source distribution for this release, and building it needs a C/C++ toolchain, so
# source builds are refused below. The hash is the GitHub-reported asset digest, checked
# against an independent download on 2026-09-10. See docs/native_runtime_handoff.md.
#
# Every line is hash-locked, which puts pip in hash-checking mode: it cannot install or
# upgrade any package that is not listed here, so this step cannot change the core pins.
# llama-cpp-python's other dependencies (numpy, jinja2, markupsafe, typing-extensions) are
# already pinned in requirements.txt and must be installed first.
#
# The wheel is not tied to one CPython ABI (tag py3-none-win_amd64), but only CPython 3.12
# x64 is supported and exercised here.
--require-hashes
--only-binary :all:
--extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
